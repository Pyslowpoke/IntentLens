# Reproducible demo / 演示脚本

Start API, worker, and web. Open http://127.0.0.1:3000.

1. New analysis → Sales synthetic sample (720 rows). Explain the synthetic label and local snapshot.
2. Keep Rule mode. Enter “分析不同地区的销售表现，找出增长机会”. Generate plans. Choose the region comparison, not order-ID grouping.
3. Wait for the real Plotly chart and result metrics. Read actual values from the result table, not a generated narrative.
4. Enter, in order: `标题：区域销售表现`, `改成蓝色`, `按数值降序`, `筛选 地区=华东`, `撤销`. Wait for each new revision. Compare the calculation-cache flag for style edits and the recomputed row count for filtering.
5. Download PNG and the default reproduction ZIP; verify that the ZIP has a hash reference but no raw data.
6. Open history, restore an older revision, then reload the page. The project, data, question and revision tree remain available.
7. For import QA, use samples/中文多工作表.xlsx, choose 中文销售, header row 2, preview, import. Show blank values and the formula-cache warning.
8. For database QA, configure the sample SQLite file or seeded PostgreSQL/MySQL readers. Browse, preview `SELECT region,SUM(amount) FROM orders GROUP BY region`, then save the snapshot. Totals are East 400 and West 200.

Automated equivalent: `pnpm e2e`. Screenshots are under docs/evidence. A recorded browser demo is generated by the dedicated capture script, when available; recordings are synthetic-only.
