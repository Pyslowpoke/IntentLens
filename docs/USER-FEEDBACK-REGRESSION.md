# 用户反馈修复与验证（2026-09-27）

## 原因与改动

1. **Excel 选错 Sheet**：原界面必须成功解析首张表后才得到 Sheet 列表，且空选择默认为第一张。新增独立 `/imports/sheets`，不依赖首张表能否解析；列出全部 Sheet（含隐藏标记）、行列数、前五行。显式选择后才能预览，后端也拒绝未选 Sheet 的 XLSX 导入。仍是一次导入一个 Sheet，不隐式合并。
2. **没有调用模型或连续讨论**：本机配置中模型和密钥已填写，但 PROVIDER 仍为 rule。已按已配置的 DeepSeek 官方地址启用 deepseek，并用真实接口验证。新增方案 analysis、澄清问题及可为空的 proposals，允许先问后做。对话存于服务端，绑定项目及数据快照，刷新后恢复；后续请求携带该讨论全部历史。上限 20 轮，达到后明确要求新讨论，不静默丢弃历史。更换数据使旧讨论失效。页面显示实际响应来源；规则模式明确声明未调用 AI。
3. **绘图失败**：最近真实失败是 Matplotlib 分类轴遇到空值。Pandas 新版的字符串转换仍可能保留空值为浮点空值；显式转换为缺失类别标签并校验数值轴。另将子进程 stderr 从无人读取的 PIPE 改为临时文件，避免大量字体警告堵塞子进程。增加轮询作为 SSE 后备，刷新后也显示最新失败任务。旧渲染缓存版本升级。
4. **真实模型字段兼容性**：真实调用发现模型返回字段显示名而非稳定 ID。只对唯一、完全匹配的显示名进行映射，并将数值轴映射到计算结果 value；未知或重名字段仍拒绝，方案继续通过计算与引擎校验。

## 测试反思与边界

此前过度依赖“API 200、任务 completed、iframe 存在”，而且主要使用平整 CSV 和规则模式。它们不能证明选对 Sheet、模型真实调用、图形非空或追问保留上下文。今后必须同时检查用户路径、输入版本、语义口径、产物内容和失败恢复。

不能保证所有问题都被发现。本次真实模型对话只验证指定合成场景，不代表所有工作簿和开放式任务均可靠。图表批量导出仍可能耗时，后台保留超时与取消；新任务失败会明确显示，用户可以修正并重试。
