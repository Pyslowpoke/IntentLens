# 观意 IntentLens

**让每一个分析意图，都有清晰的视图。**

“观”是观察数据、看见关系；“意”是理解问题与分析目的。IntentLens 将分析意图比作取景方向：先明确想了解什么，再选择合适的视图，最后回到计算依据。名称为本项目的产品命名，尚未进行商标或域名可用性核验。

## 产品概念

意图 → 视图 → 依据。产品定位是意图驱动的数据分析工作台：把业务问题转化为可审阅的分析计划，执行真实计算，呈现可视化，并给出有证据引用的决策建议。模型负责提出与解释，计算服务负责数字，用户判断与选择。

首页主张：**先理解问题，再看见答案。**

四步体验：连接数据 → 表达意图 → 验证视图 → 沉淀洞察。意图示例包括比较差异、观察趋势、理解构成；示例仅填入问题，不自动执行或声称已理解当前数据。

## 视觉语言

- 深墨绿 `#183d33`：导航与品牌识别。
- 暖白 `#f5f5ef`：长时间分析的工作画布。
- 草木浅绿 `#eaf0e0`：引导与上下文。
- 主操作绿 `#216353`：执行与确认。
- 琥珀色 `#d8ac5e`：问题与注意点。

品牌符号是包含三根数据柱的圆形取景框。首页示意用“问题卡片 → 图表取景 → 依据标签”解释产品，不展示虚构的业务指标。真实图表使用用户选择的颜色，不随品牌主题覆盖。

布局采用左侧项目导航、中间分析画布、右侧视图设置；移动端保留新建入口，将设置面板置于结果之后。按钮、边框和标题形成层级，不依赖大量装饰。尊重系统减少动态效果设置。
