## 输入与预期

三行合成数据：East 的销售额 100、300，West 200；East 访问量 1000、2000、成交数 100、400，West 访问量 1000、成交数 100。按地区销售汇总预期 East 400 / West 200；转化率必须为 ratio of sums，预期 East 500/3000、West 0.1。重复地区不是重复记录。

真实 DeepSeek API 的两个数值案例得到预期结果；本地浏览器另用规则模式检查多工作表导入、计算、连续修改、下载和刷新恢复，不能称为端到端真实模型浏览器验证。新诊断回归故意给模型虚假的 999 行摘要，验证本地统计覆盖该摘要。后台超时测试不调用轮询接口，验证任务仍会过期。

复现：`uv run pytest tests --ignore=tests/test_databases.py -q`；在 apps/web 运行 `pnpm typecheck`、`pnpm test`、`pnpm exec playwright test`（先按项目说明启动 API 和 worker）。数据库连接集成测试未在本轮执行。建议接口新增显式聚合数据发送确认。
